# BMP Crop & Rotate

Консольная утилита на C, которая вырезает прямоугольную область из 24-битного BMP-изображения, поворачивает её на 90° по часовой стрелке и сохраняет результат в новый файл.

## Сборка

```bash
make
```

Требуется GCC с поддержкой C17. Флаги компиляции: `-Wall -Werror -Wextra -pedantic`.

## Использование

```
./hw-01_bmp crop-rotate <in-bmp> <out-bmp> <x> <y> <w> <h>
```

- `x`, `y` — координаты левого верхнего угла области (отсчёт с нуля от верхнего левого угла изображения)
- `w`, `h` — ширина и высота области до поворота

Результирующее изображение будет иметь размеры `h × w`.

**Пример:**

```bash
./hw-01_bmp crop-rotate tests/lena_512.bmp out.bmp 100 100 200 150
```

## Поддерживаемый формат BMP

- Заголовок `BITMAPINFOHEADER` (DIB версия 3)
- 24 бита на пиксель (по одному байту на канал, без палитры)
- Без сжатия (`biCompression = 0`)
- Положительный `biHeight` (строки хранятся снизу вверх)

## Реализация

### Разбор заголовков

Заголовки файла и изображения (`BITMAPFILEHEADER`, `BITMAPINFOHEADER`) читаются за одну операцию `fread` напрямую в структуры. Чтобы избежать добавления компилятором байт выравнивания внутрь структур, используется `#pragma pack(push, 1)`. При загрузке проверяется сигнатура `0x4D42` (`"BM"`).

### Координатная система BMP

В формате BMP строки хранятся снизу вверх: нулевая строка в файле соответствует нижней строке изображения. При вырезании области функция `crop` учитывает это преобразованием координаты:

```c
int yCord = InfoHeader->biHeight - y - i - 1;
```

### Выравнивание строк

Каждая строка BMP выравнивается до кратности 4 байтам. Размер дополнения вычисляется как:

```c
int padding = (4 - (width * 3) % 4) % 4;
```

При чтении байты дополнения пропускаются, при записи дописываются нули.

### Поворот на 90°

После поворота изображение размером `w × h` становится `h × w`. Для каждого пикселя результата `(i, j)` исходный пиксель берётся из позиции `(w - 1 - j, h - 1 - i)`. Повёрнутый массив выделяется заново до освобождения исходного.

### Управление памятью

Пиксели хранятся в двумерном массиве строк (`pixels[row][col * 3 + channel]`). Каждый этап (загрузка → вырезание → поворот) создаёт новый массив; предыдущий освобождается сразу после.

### Обработка ошибок

Программа проверяет: количество аргументов, подкоманду `crop-rotate`, выход координат за границы (`x + w ≤ W`, `y + h ≤ H`), ошибки открытия файлов и выделения памяти. При любой ошибке выводится сообщение, программа завершается с ненулевым кодом возврата.
