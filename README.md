# Systems Programming Portfolio

Учебные проекты на C и C++, охватывающие низкоуровневую работу с памятью, файловый ввод-вывод, объектно-ориентированное проектирование и классические алгоритмы.

## Проекты

| # | Проект | Язык | Ключевые темы |
|---|--------|------|---------------|
| 01 | [Ввод-вывод на Си — база данных точек с интрузивным списком](01-c-io/) | C17 | Интрузивный связный список, `container_of`, текстовый и бинарный I/O |
| 02 | [BMP Crop & Rotate](02-c-bmp/) | C17 | Разбор бинарного формата, работа с пикселями, выравнивание строк |
| 03 | [C++ I/O: Реестр сотрудников](03-cpp-io/) | C++11 | ООП, виртуальная диспетчеризация, перегрузка операторов потоков, бинарные манипуляторы |
| 04 | [Кодирование Хаффмана](04-cpp-huffman/) | C++11 | Алгоритм Хаффмана, приоритетная очередь, побитовая упаковка, сериализация |

В каждом проекте есть `README.md` с описанием реализации, форматов данных, архитектуры и примерами использования.

## Сборка

В каждом проекте есть свой `Makefile`. Требования: GCC/G++ с поддержкой C17/C++11.

```bash
cd 01-c-io && make
cd 02-c-bmp && make
cd 03-cpp-io && make
cd 04-cpp-huffman && make
```
