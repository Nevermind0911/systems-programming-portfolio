# C++ I/O: Реестр сотрудников

Консольное приложение на C++11 для ведения списка сотрудников с поддержкой текстового и бинарного ввода-вывода в стиле C++ (перегрузка `operator<<` / `operator>>`).

## Сборка

```bash
make
```

Требования: g++, стандарт C++11.

```
make clean   # удалить артефакты сборки
```

## Использование

```
./lab-10_cppio
```

Приложение работает в интерактивном режиме. Доступные команды:

```
add <тип> <аргументы...>   — добавить сотрудника
list                        — вывести список с итоговой зарплатой
save <файл>                 — сохранить список в бинарный файл
load <файл>                 — дозагрузить список из бинарного файла
exit                        — завершить работу
```

Типы при вводе `add`:
- `1` — Developer: `add 1 <имя> <оклад> <0|1 — наличие бонуса>`
- `2` — SalesManager: `add 2 <имя> <оклад> <продажи> <цена>`

## Пример сессии

```
add 2 Joe 100 20 300
add 1 Billy 1000 1
list
1. Sales Manager
Name: Joe
Base Salary: 100
Sold items: 20
Item price: 300
2. Developer
Name: Billy
Base Salary: 1000
Has bonus: +
== Total salary: 2160

save example.edb
exit
```

## Архитектура

### Иерархия классов

Абстрактный базовый класс `Employee` хранит имя (`char*`, владеющий указатель) и базовый оклад. Два конкретных наследника:

- **`Developer`** — разработчик; зарплата = оклад + 1000 при наличии бонуса.
- **`SalesManager`** — продавец; зарплата = оклад + количество_продаж × цена_продажи × 0.01.

Полиморфизм обеспечивается четырьмя виртуальными методами (`write`, `read`, `write_bin`, `read_bin`), которые вызываются из `friend`-операторов базового класса. Такая схема позволяет добавлять новые типы сотрудников без изменения операторов ввода-вывода.

`EmployeesArray` — динамический гетерогенный массив указателей `Employee*` с удвоением ёмкости при заполнении. Владеет всеми своими объектами и освобождает их в деструкторе.

### Бинарные манипуляторы (`bin_manip.h` / `bin_manip.cpp`)

Набор вспомогательных классов-обёрток, для которых перегружены `operator<<` и `operator>>` над `std::basic_ostream<char>` / `std::basic_istream<char>`. Это позволяет использовать их с любым потоком (файловым, строковым и т.д.):

| Манипулятор | Описание |
|---|---|
| `write_le_int32(x)` / `read_le_int32(x)` | 32-битное знаковое число в little-endian (4 байта) |
| `write_bool(b)` / `read_bool(b)` | булево значение (1 байт: 0 или 1) |
| `write_c_str(s)` / `read_c_str(s, len)` | C-строка с нулевым терминатором |

### Формат бинарного файла

```
<N : int32 LE>
  <тип : int32 LE> <поля сотрудника> ...  × N
```

Тип `1` — `Developer`, тип `2` — `SalesManager`. Команда `load` дополняет текущий список данными из файла (не заменяет).

### Ключевые решения

- **Двойная диспетчеризация через виртуальные методы** — операторы ввода-вывода определены в базовом классе как `friend` и делегируют работу виртуальным `write`/`read`/`write_bin`/`read_bin`. Это разделяет интерфейс (операторы) и реализацию (переопределения в наследниках).
- **Манипуляторы как объекты** — каждый манипулятор — лёгкий класс, хранящий ссылку или значение. Перегрузка операторов для `std::basic_ostream<char>` делает их применимыми к любому типу потока, а не только к `std::ofstream`.
- **Управление памятью вручную** — `EmployeesArray` реализует динамический массив с удвоением ёмкости и корректным `delete[]` в деструкторе; `Employee` владеет `char*` для имени.
