# Кодирование Хаффмана — сжатие и распаковка бинарных файлов

Реализация двухпроходного алгоритма Хаффмана для сжатия и распаковки произвольных бинарных файлов. Написана на C++11 в объектно-ориентированном стиле.

## Сборка

```bash
make
```

Собирается исполняемый файл `hw-02_huffman`.

## Использование

```
./hw-02_huffman -c -f <входной файл> -o <выходной файл>   # сжатие
./hw-02_huffman -u -f <сжатый файл>  -o <выходной файл>   # распаковка
```

Флаги `-f`/`--file` и `-o`/`--output` можно указывать в любом порядке.

После работы программа выводит три числа в байтах:

```
<размер исходных данных>
<размер сжатых данных (без служебного заголовка)>
<размер служебного заголовка>
```

## Архитектура

### `HuffmanTreeNode`
Узел дерева Хаффмана. Хранит символ, частоту и указатели на потомков (`std::shared_ptr`). Листовые узлы определяются отсутствием потомков.

### `HuffmanTree`
Центральный класс алгоритма.

- Строит дерево через `std::priority_queue` с компаратором `Compare` (минимальная куча по частоте).
- Обходит дерево (`traverseTree`) и заполняет `codeTable` — таблицу кодов `char → vector<bool>`.
- `compress()` — кодирует строку побитово, упаковывает биты в байты (`bitsToBytes`), в начале результата сохраняет число «лишних» битов последнего байта.
- `decompress()` — по битовому потоку обходит дерево и восстанавливает исходные байты.
- Сериализация/десериализация (`operator<<`, `operator>>`) — сохраняет таблицу частот в бинарном формате: `uint32_t` (число записей), затем пары `char` + `int`.

Граничный случай с единственным уникальным символом обрабатывается отдельно: строится дерево с фиктивным родителем, при декомпрессии символ повторяется `bitCount` раз.

### `HuffmanIO`
Утилитарный класс для конвертации между `vector<bool>` (поток битов) и `vector<int>` (поток байт). Биты упакованы от старшего к младшему.

### `CompressedFile`
Представляет сжатый файл целиком. Хранит данные, дерево, число значащих битов и число лишних битов. Операторы `<<`/`>>` для `std::ofstream`/`std::ifstream` реализуют полную сериализацию/десериализацию.

## Формат сжатого файла

| Поле | Тип | Описание |
|---|---|---|
| Размер таблицы | `uint32_t` | Число записей в таблице частот |
| Таблица частот | `(char + int) × N` | Символ и его частота |
| Размер данных | `uint32_t` | Число байт сжатых данных |
| Число битов | `uint32_t` | Общее число значащих битов |
| Лишние биты | `uint8_t` | Паддинг последнего байта |
| Данные | `byte × M` | Сжатый битовый поток |

## Обработка ошибок

Все ошибки ввода-вывода и некорректные аргументы приводят к выводу диагностики в `stderr` и ненулевому коду возврата. Ошибки при чтении заголовка выбрасывают `std::runtime_error`, перехватываемое в `main`.
